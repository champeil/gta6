Solara Bay — an original open-world crime game (GTA 6 style) that runs offline in a desktop browser. A top-down 2D Canvas world with no libraries and no build step: walk, run, drive, steal anything with wheels; take seven story jobs for two fixers, run Sun Cab fares and courier parcels between them; survive a five-star police response that chases, rams, dismounts and cuffs. A compressed day/night clock, burning wrecks, a save file in localStorage, a pause sheet with a full city map, and a deterministic ?shot= mode for the four screenshots.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
